# 🚀 Interactive ATM Machine Simulator

A sleek, responsive, and fully functional **ATM Machine Web Application** built using core web technologies. This project simulates real-world banking operations directly in your browser.

---

## ✨ Features

- 🔑 **Secure Login:** Simulated PIN verification for account access.
- 💰 **Balance Inquiry:** Real-time check of your current account balance.
- 💵 **Cash Withdrawal:** Fast and secure money deduction simulation.
- 📥 **Cash Deposit:** Instant balance update upon simulated deposit.
- 📱 **Responsive UI:** Clean, modern, and user-friendly interface optimized for all screen sizes.

---

## 🛠️ Tech Stack Used

- **HTML5** - For structuring the ATM interface and layout.
- **CSS3** - For modern styling, interactive buttons, and smooth layout.
- **JavaScript (ES6)** - For handling core banking logic, state management, and user interaction.

---

## 🚀 How to Run the Project Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd ATM-machine
   ```
3. **Open the project:**
   Simply double-click the `index.html` file to launch it instantly in any modern web browser!
